## Reused and adapted components

- React / TypeScript / Vite project foundation and chapter-based typing-practice architecture.
- src/hooks/useSpeech.ts adapts the upstream file of the same path. It has been extensively changed for full-sentence speech, English-voice selection, browser capability detection, cancellation, repeat playback, stable React dependencies, and error handling.
- src/upstream/clamp.ts and src/upstream/shuffle.ts are preserved upstream utilities, used by matching, speech, backup validation, and review sessions.
- The original word-level chapter/session flow informed src/components/Practice.tsx; the sentence input, records, feedback, and local course model are new work.
